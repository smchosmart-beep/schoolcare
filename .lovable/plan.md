
# 보건일지 엑셀 다운로드 버튼 노출 개선 계획

## 확인한 현재 상태
- `src/components/admin/HealthJournal.tsx`에 이미 `엑셀 다운로드` 버튼과 `.xlsx` 다운로드 로직이 있습니다.
- 하지만 이 버튼은 `보건일지` 탭 안에만 있어서, `/admin` 첫 화면에서는 바로 보이지 않습니다.
- 그래서 사용자 입장에서는 “버튼이 없다”고 느끼기 쉬운 구조입니다.

## 구현 방향
기존 다운로드 기능은 유지하고, **관리자 페이지에서 더 잘 보이는 위치에 버튼을 추가**하겠습니다.

## 변경 계획

### 1. `src/components/admin/HealthJournal.tsx`
- 현재 있는 `handleExport` 로직은 그대로 재사용
- 버튼 문구를 더 명확하게 정리
  - 예: `보건일지 엑셀 다운로드`
- 데이터가 없을 때 비활성화/안내 상태는 유지

### 2. `src/pages/Admin.tsx`
- 관리자 상단 헤더 또는 `보건일지` 탭 진입부에 **눈에 잘 띄는 다운로드 버튼**을 추가
- 클릭 시 사용자가 바로 `보건일지` 탭으로 이동해서 다운로드할 수 있게 하거나,
- 더 좋게는 다운로드 액션을 직접 연결할 수 있도록 구조를 정리

## 권장 구현 방식
중복 구현 대신 다운로드 기능을 재사용 가능하게 정리합니다.

```text
옵션 A
Admin 헤더 버튼 → 보건일지 탭으로 이동 → 기존 다운로드 버튼 사용

옵션 B (권장)
엑셀 다운로드 로직을 공용 함수로 분리
→ Admin 헤더 버튼과 HealthJournal 내부 버튼이 같은 로직 사용
```

## 기술 상세
- 새 라이브러리 추가 불필요
- DB 변경 불필요
- 인증/RLS 변경 불필요
- 이미 설치된 `xlsx` 패키지와 현재 `visits` 조회 데이터를 그대로 활용 가능
- 중복 다운로드 로직 방지를 위해 `exportHealthJournalToExcel(...)` 같은 유틸 함수로 분리하는 방식이 가장 안전합니다

## 결과
- 관리자 페이지에서 엑셀 다운로드 버튼이 더 명확하게 보임
- 기존 보건일지 탭에서도 계속 다운로드 가능
- “버튼이 어디 있는지 모르겠다”는 문제를 해결할 수 있음



# 학생 검색 다이얼로그: 이름 검색 우선 흐름으로 변경

## 변경 사항

### `src/components/admin/DirectVisitDialog.tsx` — 전면 수정

**현재**: 학년/반 드롭다운 선택 필수 → 이름 검색
**변경**: 이름 입력만으로 전체 학생 검색 → 결과에 학년-반 표시

- 학년/반 `Select` 드롭다운 제거
- 이름 검색 `Input`만 남김
- `filteredStudents`: 검색어가 2글자 이상이면 전체 학생에서 이름 매칭, 번호 매칭
- 결과 목록 각 항목에 `{grade}학년 {class}반 {number}번 {name}` 형태로 표시
- 동명이인도 학년-반-번호로 구분 가능
- 검색어 없으면 "이름을 입력해주세요" 안내

```text
┌─ 학생 검색 ──────────────────────┐
│ [🔍 이름으로 검색...           ] │
│                                   │
│  1학년 2반 3번 김민수             │
│  3학년 1반 12번 김민수            │
│  ...                              │
└───────────────────────────────────┘
```

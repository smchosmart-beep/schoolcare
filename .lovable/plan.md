

# 보건일지 앱 (School Health Journal)

## 디자인 시스템
- **Primary**: #036635 (그린) — 버튼, 헤더, 주요 액션
- **Secondary**: #F9C74F (옐로우) — 강조, 알림, 상태 뱃지
- **Navy**: #2A3D45 — 텍스트, 카드 배경, 네비게이션
- **배경**: 밝은 오프화이트 (#F8F9FA)
- 부드러운 그림자, 둥근 카드, 깔끔한 타이포그래피로 전문적인 느낌 구현

## 페이지 구조

### 1. 인증 페이지 (`/login`, `/signup`)
- 보건교사 회원가입/로그인 (이메일+비밀번호)
- Lovable Cloud Auth 사용

### 2. 키오스크 모드 (`/kiosk`)
- **첫 화면**: [스스로 치료] [보건선생님 만나기] 큰 버튼 + 현재 대기자 수 & 대기자 명단 표시
- **학생 선택 플로우**: 학년 선택 → 반 선택 → 번호+이름 선택 (업로드된 엑셀 명단 기반, localStorage에서 로드)
- **스스로 치료**: 보건교사가 설정한 처치 목록(물파스, 밴드 등)에서 선택 → 기록 저장 → 첫 화면 복귀
- **보건선생님 만나기**: 대기열에 추가 → 첫 화면 복귀
- 터치 친화적 큰 버튼, 태블릿 최적화 UI

### 3. 보건교사 관리 페이지 (`/admin`)
- **대시보드**: 스스로 치료 학생 명단 / 보건선생님 대기 학생 명단 (실시간 Supabase Realtime 구독)
- **학생 상세 기록 입력**: 학생 클릭 시 모달/패널로 건강문제, 처치 및 조치, 투약내용 입력 → 처치 시간 자동 기록
- **스스로 치료 항목 설정**: 학생들에게 보여줄 간단 처치 목록 관리 (추가/수정/삭제)
- **학생 명단 업로드**: NEIS 엑셀 파일 업로드 → 파싱 후 localStorage에 저장 (DB 저장 안 함)
- **보건일지**: 일별/주별/월별 기록 조회 + 엑셀 다운로드 기능

## 데이터베이스 (Lovable Cloud)
- **visits 테이블**: 방문 기록 (학생 정보, 방문 유형, 건강문제, 처치내용, 투약, 시간)
- **self_treatment_options 테이블**: 스스로 치료 항목 목록
- **waiting_queue 테이블**: 보건선생님 대기열 (실시간 구독)
- RLS 정책: 각 보건교사는 자기 학교 데이터만 접근

## 네이티브 앱 (Capacitor)
- Capacitor 설정으로 iOS/Android 네이티브 앱 빌드 가능하도록 구성
- 태블릿 키오스크 모드에 최적화

## 핵심 기능 요약
1. 보건교사 인증 & 관리
2. NEIS 엑셀 명단 → 로컬 저장
3. 키오스크 학생 셀프 접수 (스스로 치료 / 보건선생님 만나기)
4. 실시간 대기열 & 방문 명단
5. 건강 기록 입력 → 보건일지 생성
6. 일/주/월별 보건일지 조회 & 엑셀 내보내기

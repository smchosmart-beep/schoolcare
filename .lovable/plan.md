# 잘못 연결된 방문기록 정정 기능

## 확인된 사실 (업로드하신 엑셀 대조 결과)

- 엑셀 897행에는 학생별 `이름 / 학년-반 / 번호`가 모두 정확히 들어 있고, 이관된 기록의 좌표도 정확합니다. 예: `오주안 2-매 9번, 3.26 밴드` — 이관분에서 오주안 기록은 이 1건뿐입니다.
- 문제의 나머지 19건은 이관 데이터가 아니라 앱에서 실제로 생성된 기록입니다(작성 시각이 4~8월에 걸쳐 있고, 이관은 9월 2일에 한 번에 들어감).
- 그 19건의 날짜(4/16, 6/2, 8/21 등)는 업로드하신 엑셀에 들어 있지 않습니다. 이 파일은 26일치(897건)만 담고 있어서, 해당 기록의 실제 학생을 이 파일로는 찾아낼 수 없습니다.
- 즉 앱 기록에는 `2학년 매반 9번 오주안`으로만 저장돼 있고, 실제 학생을 알려주는 다른 단서가 데이터에 없습니다. 그래서 **현재 가진 자료만으로는 자동 정정이 불가능**합니다.

## 그래서 두 가지를 함께 만듭니다

### 1) 행별 정정 기능 (지금 바로 사용 가능)

방문기록 화면의 각 기록 행에 "학생 정정" 버튼을 추가합니다.

- 버튼을 누르면 학생 선택 창이 열립니다(이름 검색 + 학년·반 선택 두 가지 방식, 직접기록 창과 동일한 방식).
- 학생을 고르면 그 기록의 학년·반·번호·이름이 새 학생으로 바뀌고, 목록이 즉시 새로고침됩니다.
- 기록 내용(증상·처치·투약·날짜)은 그대로 보존되며 삭제는 일어나지 않습니다.
- 여러 건을 체크해서 같은 학생으로 한 번에 옮기는 일괄 정정도 지원합니다.

### 2) 엑셀 기반 자동 후보 추천 (선택)

NEIS 보건일지를 4~8월 전체 기간으로 다시 내려받아 올려주시면, 정정 창에서 그 기록의 **날짜·증상·처치가 일치하는 엑셀 행**을 후보로 자동 제시합니다. 후보를 한 번 클릭하면 정정 완료 — 학생을 일일이 찾을 필요가 없습니다. 자동 반영이 아니라 항상 확인 후 적용하는 방식입니다.

## 기술 사항

- `src/components/admin/StudentRecords.tsx`: 기록 행에 정정 버튼/체크박스 추가, 학생 선택 다이얼로그(신규 컴포넌트 `VisitReassignDialog.tsx`) 연동.
- 정정은 `visits` 테이블의 `student_grade / student_class / student_number / student_name` UPDATE만 수행. 기존 `Teachers can update their own visits` 정책으로 충분하고, 이름은 업데이트 트리거가 자동 재암호화합니다. 스키마 변경 없음.
- 엑셀 후보 매칭은 브라우저에서 `xlsx`로 파싱(기존 NEIS 가져오기와 같은 방식), 서버 저장 없음. 매칭 키는 날짜 + 처치/증상 문자열 유사도.
- 정정 후 기존 페이징 조회를 다시 실행해 화면을 갱신합니다.

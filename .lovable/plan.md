# 잘못 연결된 방문기록 정정 기능

## 확인된 사실 (DB 원본 대조)

- 이관된 엑셀 892건은 좌표(학년·반·번호·이름)가 모두 정확합니다. 오주안의 이관 기록은 3.26 밴드 1건뿐입니다.
- 오주안 목록에 섞인 나머지 19건은 이관 자료가 아니라 앱(스쿨케어)에서 실제로 등록된 기록으로, DB에 암호화된 이름 자체가 모두 '오주안'입니다. 복호화 오류가 아니라 저장 시점부터 이름이 잘못 들어갔습니다(키오스크에서 2-매 반 화면의 오주안 칸을 누른 것으로 추정).
- 기록에는 실제 학생 정보가 남아 있지 않으므로 자동 복원이 불가능합니다. 기록의 날짜·증상·처치를 보고 실제 학생을 지정해 고치는 수동 정정 기능이 필요합니다.

## 만들 것: 기록별 학생 정정 기능

방문기록 탭의 기록 행에 "학생 정정" 기능을 추가합니다.

- 각 기록 행에 체크박스 + "정정" 버튼을 표시합니다.
- 정정 버튼을 누르면 학생 선택 창이 열립니다: 이름 검색 / 학년·반 선택 두 가지 방식(직접기록 창과 동일).
- 학생을 고르면 선택한 기록의 학년·반·번호·이름이 그 학생으로 바뀌고 목록이 즉시 갱신됩니다.
- 여러 건을 체크해서 같은 학생으로 한 번에 옮기는 일괄 정정을 지원합니다(오주안에 몰린 19건 정리에 유용).
- 기록 내용(날짜·증상·처치·투약)은 그대로 보존, 삭제는 없습니다.

## 기술 사항

- `src/components/admin/StudentRecords.tsx`: 행에 체크박스·정정 버튼 추가, 다중 선택 상태 관리.
- 신규 `src/components/admin/VisitReassignDialog.tsx`: 이름 검색 + 학년·반 선택으로 대상 학생 지정.
- 정정은 `visits`의 `student_grade / student_class / student_number / student_name` UPDATE만 수행. 기존 정책(`Teachers can update their own visits`)으로 충분하며, 이름은 업데이트 트리거가 자동 재암호화. 스키마 변경 없음.
- 정정 후 기존 페이징 조회로 목록 갱신.

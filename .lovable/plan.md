

## 학생 명단 그리드 배치 + 모달 너비 확대

### 변경 파일
`src/components/admin/DirectVisitDialog.tsx`

### 변경 내용

**1. 모달 너비 확대**
- `DialogContent`의 `sm:max-w-lg` → `sm:max-w-3xl`로 확대 (5열 그리드가 여유 있게 들어감)

**2. 학생 명단 레이아웃 변경**
- 기존: 세로 1열 + `max-h-64 overflow-y-auto` 스크롤
- 변경: `grid grid-cols-5 gap-2`로 5명씩 가로 배치, 스크롤 제거
- 학생 버튼은 정사각형에 가까운 카드 형태(번호·이름 표시)로 컴팩트하게

**3. 영향 범위**
- 이름 검색 탭의 결과 리스트는 기존대로 유지(이름 검색은 결과 수가 가변적이라 스크롤이 자연스러움)
- 그리드 선택 → 학생 카드 영역만 변경

### UI 예시
```text
┌─ 3-1 학생 선택 (← 뒤로) ─────────────────────┐
│ [1번 김OO] [2번 이OO] [3번 박OO] [4번 ...] [5번 ...] │
│ [6번 ...]  [7번 ...]  [8번 ...]  ...                │
└──────────────────────────────────────────────┘
```

### 안전성
- 순수 UI 레이아웃 변경, 데이터/상태/콜백 로직 무변경
- 한 반 학생 수가 30명 내외라 5열 = 6행으로 한 화면에 충분히 들어감

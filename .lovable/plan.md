# NEIS 보건일지 엑셀 가져오기

## 목표
NEIS에서 내려받은 보건일지 엑셀을 스쿨케어로 이관한다. 업로드한 파일(2026.3.4~4.8, 26일치, 897건)을 포함해 앞으로도 관리자 화면에서 직접 올릴 수 있게 한다.

## 파일 구조 파악 결과
날짜별 블록이 반복되는 형식이며, 각 블록에서 다음을 읽는다.
- 날짜: `2026. 3. 4.(수)` 형식
- 학생 행: 순서 / 이름 / 학년반(`3-난`) / 번호 / 성별 / 증상 / 처치

## 변경 내용

### 1. 신규 컴포넌트 `src/components/admin/NeisImport.tsx`
- 엑셀 업로드(기존 `xlsx` 라이브러리 사용) → 날짜 블록 단위 파싱
- 미리보기: 총 건수, 기간, 날짜별 건수, 상위 몇 건 샘플 표시
- "가져오기" 실행 시 로그인한 보건교사 계정으로 `visits`에 일괄 저장
  - `student_grade`/`student_class`(`3-난` → 3, `난`)/`student_number`/`student_name`
  - `health_issue` = 증상, `treatment` = 처치
  - `visit_type` = `teacher_visit`, `status` = `completed`
  - `visited_at` = 해당 날짜 09:00부터 순서대로 1분 간격
  - 이름은 기존 DB 트리거가 자동 암호화
- 학생 명단 동시 등록: 기록에 등장한 학생을 `학년-반-번호` 기준 중복 제거 후 `addStudent()`로 로컬 명단에 추가
- 중복 방지: 가져오기 전 같은 기간의 기존 기록을 조회해 (날짜+학년+반+번호) 중복 건은 건너뛰고, 건너뛴 수를 결과에 표시
- 500건 단위로 나눠 저장하고 진행률 표시

### 2. 배치 위치: `src/pages/Admin.tsx`
- "학생관리" 탭 안에 기존 학생 명단 업로드 카드 아래로 배치 (탭 추가 없음)

### 3. 이번 파일 이관
기능 완성 후, 업로드해 주신 파일을 같은 로직으로 선생님 계정에 이관하고 결과(등록 건수, 학생 수)를 보고

## 기술 메모
- DB 스키마 변경 없음 — 기존 `visits` 테이블과 RLS 정책 그대로 사용
- 성별 열은 현재 스키마에 없어 저장하지 않음
- 통계·비고 행은 파싱 대상에서 제외
